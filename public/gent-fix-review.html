Gent Frontend Fix Review

This frontend branch is rebuilt from the old design baseline commit e996e2a8231aaa259b075f192687146327785cc5. The changes are functional compatibility fixes only, with unsupported marketing copy removed from the public pages touched in this pass.

Authentication

  • Raised Axios timeout for Render cold starts.
  • Stopped auth endpoints from retrying stale refresh tokens.
  • Stored tokens under both old and CLI-aligned keys.

Dashboard

  • Recent Activity now loads repositories and commits from the API.
  • Recent Activity View opens the matching repository route.
  • Repository sorting supports Newest, Oldest, and Name.
  • Sidebar repository links open the real dashboard route.

Repository Code

  • Empty repositories can create the first file from the web UI.
  • Branch file trees resolve from the selected branch commit.
  • File viewer now includes lightweight syntax highlighting.

CLI Compatibility

  • Clone URLs use /api/repos/<owner_id>/<repo_name>.
  • Instructional examples use Gent CLI commands.
  • Dark-mode dropdown options remain readable.

Public Pages

  • Top and bottom banners now link to Home, CLI Docs, FAQ, and Dashboard.
  • FAQ now contains real Gent CLI, API, repository, branch, member, and account answers.
  • Removed unsupported support/demo/notification CTA content from FAQ.

Create and Delete Smoke

  • Repository name validation now matches the backend: letters, numbers, dashes, and underscores.
  • Create/update hooks unwrap backend { repository } responses.
  • Live smoke test created a repo, pushed first file data, cloned it with CLI, and deleted it.

Team Documentation

  • Frontend fix notes are written in docs/frontend-fixes-and-qa.md.
  • The document lists touched frontend behavior, API routes, CLI compatibility, and verification boundaries.
